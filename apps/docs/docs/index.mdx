# Introduction

NextBase is an open-source backend for Next.js. It runs inside your app and
gives it a Postgres database, authentication, access rules and a REST API,
with a typed client SDK for the browser, server components and server actions.
Whether you are building a blog, a team workspace or a SaaS product, there is
no separate backend to deploy, host or keep in sync, so you can focus on your
app instead of its plumbing.

:::warning

NextBase is in early development and not recommended for production yet.
Until version 1.0, releases may change the API and the database layout, and
upgrading may need manual steps described in the changelog.

:::

## Features

NextBase aims to be everything an app needs from a backend, without leaving
Next.js. It provides the essentials out of the box, from your data and who
may access it to signing users in. Here are some of the features:
