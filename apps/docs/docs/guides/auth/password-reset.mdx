# Password reset

A user who forgot their password asks for a link by email and chooses a new
password on a page in your app. It needs
[email sending](/docs/guides/auth/email).

## Send the link

```ts
await nb.collection("users").requestPasswordReset("ann@example.com");
```

The call resolves the same way whether or not the address belongs to an
account, so it reveals nothing about who has signed up.

## Set the new password

The email links to `/reset-password?token=...` in your app. That page asks for
the new password and confirms it:

```ts title="app/reset-password/actions.ts"
"use server";
import { redirect } from "next/navigation";
import { nb } from "@/lib/nextbase";

export async function resetPassword(form: FormData) {
  const client = await nb();
  await client
    .collection("users")
    .confirmPasswordReset(
      String(form.get("token")),
      String(form.get("password")),
      String(form.get("passwordConfirm")),
    );
  redirect("/sign-in");
}
```

After a reset:

- the link cannot be used again, even by requests sent at the same time,
- every session of the account ends, so the user signs in again,
- the email counts as verified, since the user proved they receive it; if it
  was not verified before, [providers linked](/docs/guides/auth/oauth2#link-and-unlink-providers)
  to the account are unlinked, as whoever linked them may not own the email,
- a sign-in block from failed attempts is lifted,
- the owner gets an email saying the password changed.
