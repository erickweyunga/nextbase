# NextBase brand assets

| Asset | Use | Files |
| ----- | --- | ----- |
| Logo | the mark and the wordmark together; the default | `nextbase-logo-*` |
| Wordmark | the name alone, where the mark is already shown | `nextbase-wordmark-*` |
| Mark | the symbol alone, in tight spaces | `nextbase-mark-*` |
| Icon | the mark centered on a square, for favicons and avatars | `nextbase-icon-*` |

- `-dark` is the `#111111` version for light backgrounds; `-light` is white,
  for dark backgrounds.
- Prefer the SVGs in `svg/`. The PNGs in `png/` have transparent backgrounds:
  icons at 512 px, marks 512 px tall, logo and wordmark 1600 px wide.
- The SVGs have no padding. Leave clear space around the logo of at least the
  mark's width.
- `source.png` is the original artwork the vectors were made from: the mark is
  rebuilt as exact geometry, the wordmark is traced.

## Name

In text, write the name as **NextBase**. The lowercase "nextbase" in the logo
is part of the design, not the spelling.
