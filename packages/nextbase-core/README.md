# @nextbasejs/core

A backend for your app on Postgres: collections, access rules, auth and sessions, auto-generated APIs and an admin UI. It runs inside your app and works with any framework that speaks web-standard `Request` and `Response`.

> Early development. Not ready for production use.

## Packages

- `@nextbasejs/core`: the backend and the `nextbase` CLI
- `@nextbasejs/client`: the SDK, for browsers and any JavaScript runtime
- `@nextbasejs/next`: Next.js integration
- `@nextbasejs/react`: React provider and hooks
